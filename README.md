## 👋 About Me

Hey there! I'm **Vedank**, a developer who loves building systems that stay fast, correct and observable under real-world load. I like taking an idea from a whiteboard sketch to a tested, containerized, CI-verified service.

- 🔭 I’m currently working on **event-driven backends**: a real-time payment transaction switch (Spring Boot + Kafka) and **SentinelAI**, an automated pull-request reviewer (Go + Python + Redis).
- 🌱 I’m currently learning **Kubernetes, Terraform and distributed-systems internals**: consensus, event sourcing and CQRS.
- 🧵 I enjoy **concurrency problems**: lock-free rate limiters, thread-safe caches, multi-threaded crawlers.
- 🎯 My goal is to grow into a **backend/platform engineer** who ships reliable, well-tested infrastructure.
- 💬 Ask me about **Java, Spring Boot, Kafka, Docker, or system design**. Always happy to chat!
